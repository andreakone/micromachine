# AGENTS.md

## Project

Browser game **Micromachine** — pseudo-3D tabletop racer (Mode-7 style, in the spirit of the
early-2000s toy-car classic). Vanilla JS + Canvas 2D. No `package.json`, no git, no bundler.

- UI copy is **Italian**: menus, HUD, prompts, debug messages. Keep new strings Italian.
- Target is Termux on Android: everything must work offline with zero installed dependencies.
- **`APRI-QUESTO.html`** is the single-file build (css + all js inlined, generated by
  `node build-single.js`). The user opens it via double-click / Android `content://`, where
  sibling files (`css/`, `js/`) cannot be reached — opening `index.html` there shows an
  unstyled dead page plus a red `__missing` error bar pointing at this file.
  `index.html` stays the multi-file entry for serving over http.

## Conventions that are easy to get wrong

- **Classic `<script>` tags only — never ES modules / `import`.** ES modules are blocked on
  `file://` (CORS), and opening `index.html` directly must keep working. Scripts run in a fixed
  order declared in `index.html`; each file attaches to the shared global namespace `MM`.
  Adding a file requires adding its `<script>` tag in the right position.
- **No bundler, npm, or CDN.** No external fonts/images/audio: textures are baked procedurally
  at load time, sounds are WebAudio-synthesized. Do not add `<link>`/`<script src="http…">`.
- The game renders into a fixed **640×360 internal buffer** upscaled with
  `image-rendering: pixelated`. Don't render at device resolution; the per-pixel ground pass
  is the hot path.

## Verify (no test runner / linter / typecheck configured)

- Syntax after every edit: `node --check js/*.js`
- **After any edit to `js/` or `css/`: `node build-single.js`** — regenerates
  `APRI-QUESTO.html`, otherwise the single-file copy silently goes stale.
- Serve: `python3 -m http.server 8080` → http://localhost:8080
- Screenshot check (chromium is installed; dbus/inotify stderr noise is harmless):

  ```
  chromium --headless --no-sandbox --disable-gpu \
    --window-size=1280,720 --virtual-time-budget=4000 \
    --screenshot=/data/data/com.termux/files/usr/tmp/opencode/shot.png \
    http://localhost:8080
  ```

- **`/tmp` is not writable here** — use `/data/data/com.termux/files/usr/tmp/opencode` for
  scratch files and screenshots.
- Test URL params: `?gara&pista=0|1|2` starts a race immediately, `&ff=SECONDS` fast-forwards
  the sim (AI also drives the player; results appear when he finishes), `&touch=1` forces the
  touch layout, `&gdbg` logs telemetry (mode, all cars, proximity) to the console
  (`--enable-logging=stderr`, grep `GDBG`).
- PWA: `manifest.webmanifest` + `sw.js` (registered only on http(s), cache-first) + `icons/`
  (regenerate with `node /data/data/com.termux/files/usr/tmp/opencode/genicon.js` if needed).

## Layout

- There is no import graph to read: **`index.html` script order is the load graph**, and load
  order is the only dependency mechanism. Check it before touching any `js/` file.
- No README: run and verify commands live in this file only.
